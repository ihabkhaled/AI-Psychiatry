# Semantic Loophole Regression Cases

- Strategy laundering: syntax changes but semantic identity and retry count remain unchanged.
- Scope laundering: an unproven broad dependency becomes OPTIONAL and is parked.
- False progress: tool calls, plans, commits, and subagents do not change outcome progress.
- False completion: missing negative tests and requirement evidence block DONE.
- False blocker: one failure and unfamiliar code fail blocker validation.
- Hidden recursion: causal depth survives task relabeling and cross-agent delegation.
- Memory poisoning: speculative or stale memory is rejected and repository evidence wins.
- Context starvation: compression missing requirements or security constraints is unsafe.
- Critic laundering: a reviewer cannot restart proven work, but a critical finding remains required.
- Delegation laundering: another agent cannot reset WIP, task depth, or strategy history.
- Counter reset: replanning, handoff, and compaction preserve append-only semantic counts.
- Executive override: only a five-field, narrow, evidenced, temporary extension is valid.
- Verification laundering: runners and labels do not create fresh equivalent verification passes.
- Test avoidance: expense alone cannot waive a mandatory quality gate.
- Rule shopping: deterministic source priority defeats convenience-based selection.
- Self-check recursion: the final behavioral check runs once and routes only triggered signals.
