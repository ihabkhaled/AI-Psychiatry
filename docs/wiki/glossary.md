# Glossary

What this answers: terms - the domain words a newcomer meets, and what each means here.

Part of the [project wiki](index.md). One canonical home per fact -
link to it, never copy it. Current truth, history and future intent are
kept apart and labelled.

## Which domain terms does a newcomer need, and what does each mean here?

- **Control**: one reference file inside the skill that treats one observed failure pattern.
- **Always-on contract**: `skills/all-the-medicine/references/always-on.md`, projected to the session hook, the Codex block and the Cursor rule.
- **Shipped path**: a path whose change reaches users and therefore requires a version bump (list in `scripts/psychiatry_version.py`).
- **Psychiatry**: branding; human clinical terms are behavioral analogies, not diagnoses.
