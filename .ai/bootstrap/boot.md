# Mandatory Bootstrap

Before planning, auditing, or modifying code:

1. State the primary objective and lock it.
2. Load repository constraints and relevant context only.
3. Identify evidence, current state, and the smallest next action.
4. Classify discoveries as blocker, required, optional, or unrelated.
5. Define completion proof and stop when it is satisfied.

Do not store hidden reasoning. Record only decisions, evidence, actions, blockers, and results.
