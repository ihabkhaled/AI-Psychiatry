## What are the main components, how does data flow between them, and which external systems does it integrate with?

Components, each verifiable in the tree:

- The one skill, `skills/all-the-medicine/` (`SKILL.md` plus `references/`: the always-on contract, execution phases, and the controls under `references/skills/`).
- Hooks, `hooks/hooks.json`: `SessionStart` prints the contract, `UserPromptSubmit` prints a three-line reminder. Both only print and exit 0.
- Installers, `install.sh` and `install.ps1`: Claude Code via the plugin marketplace; Codex via a marked block in `AGENTS.md` plus the skill under `~/.agents/skills`; Cursor via an `alwaysApply` rule plus the skill.
- The `.ai/` runtime that the install-framework control writes into a target repository: rules, manifests, guides, policies, memory, state.
- Build and check scripts under `scripts/`; the version tool is `scripts/psychiatry_version.py`.

Data flow: `always-on.md` is the one source; the session hook, the Codex block and the Cursor rule are projections of it. The compiled references are generated by `scripts/build_all_the_medicine.py`.
