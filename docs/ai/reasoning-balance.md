# Reasoning Balance

Reasoning balance classifies observable state as insufficient, sufficient, or excessive. Insufficient state has critical unknowns or missing required evidence. Sufficient state is decision-ready. Excessive state repeats investigation after sufficient evidence.

Use [`reasoning-balance`](../../skills/all-the-medicine/references/skills/reasoning-balance/reasoning-balance.md) to choose one action: investigate, execute, verify, or stop. Time, token count, command count, and discomfort do not determine the state. See the [operational controller](../../.ai/guides/reasoning-balance.md).
