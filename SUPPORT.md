# Support

AI-Psychiatry support is provided through the public GitHub repository:

- Issues: https://github.com/ihabkhaled/AI-Psychiatry/issues
- Source and documentation: https://github.com/ihabkhaled/AI-Psychiatry

Before opening an issue, include the plugin version, host platform and version, the skill or rule involved, the observable behavior, the expected behavior, and a minimal reproducible example. Remove secrets, access tokens, private repository content, and personal information. For installation failures, also include the validation command and sanitized output.

Use GitHub security reporting or a private maintainer contact when the repository exposes one for vulnerabilities that should not be public. Do not include exploitable secrets or sensitive user data in a public issue.

Support is offered on a best-effort basis. There is no guaranteed response time or service-level agreement. Questions about Claude or OpenAI account access, billing, marketplace review, or host behavior should be directed to the relevant platform provider.
