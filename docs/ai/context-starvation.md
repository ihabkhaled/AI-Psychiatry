# Context Starvation

Context starvation occurs when compression or minimal reading removes requirements, security or architecture constraints, decisions, blockers, evidence, or remaining work. Its opposite is context overload from unrelated bulk.

Use [`context-balance`](../../skills/all-the-medicine/references/skills/context-balance/context-balance.md). Preserve required meaning, remove redundancy, and load only missing authoritative sources. Repository evidence outranks durable memory. See [context-balance guidance](../../.ai/guides/context-starvation.md).
