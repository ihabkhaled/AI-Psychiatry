# Change - Always followed (loud), version discipline, uninstall cleanup (0.7.0)

- **When:** 2026-10-03
- **Who / agent:** Ihab Khaled (owner); Claude Code (Sonnet 5.5)
- **Source:** owner request "must ALWAYS be followed automatically, bump the version always, document it", plus the incident below
- **Status:** implemented

## Before

AI-Psychiatry was always on through a `SessionStart` hook, a Codex `AGENTS.md` block and a Cursor `alwaysApply` rule, all printing a polite contract. Nothing reminded the agent on each prompt. Versions lived in several manifests with a hand-run consistency test and no rule tying a shipped change to a version bump. `--uninstall` left the downloaded source cache `~/.ai-psychiatry/src` behind.

## Change

- A `UserPromptSubmit` hook (`hooks/prompt-reminder.sh`, exec form) prints three short loud lines per prompt. `SessionStart` keeps no matcher.
- The contract (`skills/all-the-medicine/references/always-on.md`, the one source for the session hook, the Codex block and the Cursor rule) and the skill now open with a loud, tough-love headline aimed at the AI only.
- `scripts/psychiatry_version.py` and rule 58 (`.ai/rules/58-version-discipline.md`), a CI workflow (`.github/workflows/ci.yml`), and two test files.
- Both installers remove the download cache on uninstall, only when it is an AI-Psychiatry checkout.
- `.env` is now gitignored (the security extractor flagged it).

## Now

Every prompt carries the reminder; every shipped change must raise the version and add a CHANGELOG section, or CI fails. Uninstall leaves nothing behind (tested for `install.sh` and, on Windows, `install.ps1`).

## Why

Incident, 2026-10-03: an agent ignored the installed plugin until the owner shouted at it, then complied. A quiet contract is skipped; a loud one on every prompt is not. The register is deliberate: playful, aimed at the AI, never at the human, no profanity. See [ADR 0001](../adr/0001-loud-always-on-hooks-and-version-discipline.md).
